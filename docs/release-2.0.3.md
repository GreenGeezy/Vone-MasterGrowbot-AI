# iOS 2.0.3 (182)

Build 182 unifies the splash and onboarding background, improves the grow-coach headline, and makes the splash the first persistent localhost preview. This update also fixes the blank screen after onboarding by returning actual AppScreen enum values rather than uppercase strings. Home now shows a branded grow overview with plant, due-task, and check-in counts and clear routes into the journal and plant health tools. Navigation and completed reports reset their scroll position. Touch-device text fields use at least 16px to prevent iOS focus zoom, the report header respects the safe area, and report content wraps within the screen. Pinch zoom remains available.

The onboarding summary leads with Start 3-Day Free Trial and explains eligibility. The paywall uses that CTA only for an eligible, confirmed free offer; otherwise it says Continue beside the billing terms. No CTA advertises Pro. Onboarding mentions shareable reports. Journal has no Premium prompt; the Plant Health and strain-library Premium routes remain. A generated grower-and-Growbot high-five scene, indoor plants, a background grower, and the requested Best Buds trophy cover native startup and the first web paint. A refreshed, skippable four-screen tutorial opens after verified subscription access when this tutorial version has not been completed. Replay it in Profile → Settings & Support → View Tutorial.

Before App Store submission, install build 182 through TestFlight without uninstalling an existing anonymous installation. Check Home, each tab, strain search and selection, report scrolling, and keyboard dismissal. Use a fresh sandbox account or reset introductory-offer eligibility to test the three-day trial, then check cancellation, restore, and Premium without a trial. Confirm the tutorial opens after first verified access and replays from Settings. The native launch storyboard and keyboard behavior require device verification; browser emulation cannot establish that the signed iOS build is error-free.
